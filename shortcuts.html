10 Apple Shortcuts recipes for Tesla and Apple Home

Exact recipes to rebuild in the Shortcuts app. Personal automations: Shortcuts > Automation > +. Regular shortcuts: Shortcuts > +. Recipes only, no iCloud links.

⬇ Download free PDF: 10 Shortcuts Recipes

Verification note: Tesla action names (Precondition Vehicle (some app versions show it as "Start Preconditioning"), Set Temperature, Defrost, Lock/Unlock, Open Frunk, Open/Close Rear Trunk, Set Charge Limit, Sentry Mode, Dog Mode) come from the Tesla app 4.24 Shortcuts list as reported by MacRumors. Tesla's Owner's Manual doesn't publish the exact names, so check the "Tesla" section in your Shortcuts app. Apple names (Control Home, Get Current Weather, If, Wait, Show Notification, and the triggers) match Apple's Shortcuts docs.

1. Warm Up Tesla

Trigger: Siri / Home Screen (regular shortcut)

Actions

  1. Tesla: Precondition Vehicle: On, Vehicle: your car
  2. Tesla: Set Temperature: 70 °F
  3. Show Notification: "Cabin warming"

Run without asking: Regular shortcuts run when you tap them or ask Siri.

Tip: Say "Hey Siri, Warm Up Tesla".

2. Cold Morning Pre-Heat

Trigger: Personal automation: Time of Day, 7:00 AM, Weekdays

Actions

  1. Get Current Weather: Current Location
  2. Get Details of Weather Conditions: Temperature
  3. If: Temperature is less than 40
  4. Tesla: Precondition Vehicle: On
  5. Tesla: Defrost: On
  6. End If

Run without asking: Time of Day can run without asking: turn off Ask Before Running.

Tip: Pair with Scheduled Precondition for regular commutes.

3. Arrive Home: Garage

Trigger: Personal automation: Arrive, Home

Actions

  1. Control Home: Set Scenes and Accessories, Garage Door: Open
  2. Control Home: Garage and Porch Lights: On

Run without asking: Arrive automations have a Run Immediately option (iOS 17+). Garage doors may still ask for confirmation.

Tip: Or build it as a Home app "People Arrive" automation for the whole household.

4. Leave Home: Lock Up

Trigger: Personal automation: Leave, Home

Actions

  1. Tesla: Lock
  2. Control Home: Garage Door: Closed
  3. Control Home: Scene "Away"

Run without asking: Use Run Immediately (iOS 17+).

Tip: Needs a home hub to control accessories remotely.

5. CarPlay Connected: Leaving Lights

Trigger: Personal automation: CarPlay, Connects

Actions

  1. Control Home: Driveway Lights: On
  2. Wait: 300 seconds
  3. Control Home: Driveway Lights: Off

Run without asking: CarPlay automations can run without asking.

Tip: Limit it to evenings with an If on Current Date (optional).

6. CarPlay Disconnected: Plug-In Reminder

Trigger: Personal automation: CarPlay, Disconnects

Actions

  1. Show Notification: "Plug in the car?"

Run without asking: CarPlay automations can run without asking.

Tip: If your car doesn't use CarPlay, use Bluetooth > your Tesla > Disconnects (Run Immediately on iOS 17+).

7. Groceries: Open Trunk

Trigger: Siri / Back Tap / Action button

Actions

  1. Tesla: Open/Close Rear Trunk: Vehicle: your car

Run without asking: Runs when triggered.

Tip: Assign it to Back Tap: Settings > Accessibility > Touch > Back Tap.

8. Garage NFC Tag: Good Night

Trigger: Personal automation: NFC (scan a tag by the garage door)

Actions

  1. Tesla: Lock
  2. Tesla: Sentry Mode: On
  3. Control Home: Garage Door: Closed
  4. Control Home: Scene "Good Night"

Run without asking: NFC automations can run without asking.

Tip: Stick the NFC tag at hand height by the door into the house.

9. Off-Peak Charge Limit

Trigger: Personal automation: Time of Day, Sunday 8:00 PM

Actions

  1. Tesla: Set Charge Limit: 80%
  2. Show Notification: "Charge limit set to 80%"

Run without asking: Time of Day can run without asking.

Tip: Before road trips, make a matching "Trip Mode" shortcut that sets 100%.

10. Pet Safe Stop

Trigger: Siri / Home Screen

Actions

  1. Tesla: Dog Mode: On
  2. Show Notification: "Dog Mode on"

Run without asking: Runs when triggered.

Tip: Always check the cabin temperature in the Tesla app before leaving a pet.
